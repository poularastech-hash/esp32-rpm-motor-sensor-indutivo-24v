# esp32-rpm-motor-indutivo-24v
Projeto prático desenvolvido na bancada demonstrando como realizar a leitura de rotação (RPM) de um motor de indução trifásico usando um **sensor indutivo 24Vcc** integrado ao **ESP32**, além do acionamento de um **relé de interface 24Vcc** via **Monitor Serial** e acompanhamento em tempo real alterando a frequência de giro do motor.
